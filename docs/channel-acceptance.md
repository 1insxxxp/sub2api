# 账号渠道验收

入口：账号管理 → 更多 → 渠道验收；勾选账号后可批量验收。完整管理员可操作，二级管理员和受限管理密钥不可使用。

标准套餐按账号支持的协议安排最多 17 次合成生成请求，有同来源计数接口时增加最多 3 次计数请求，可额外选择长上下文、图片、音频、工具调用。检测固定账号，不参与号池切换。通过模型映射选择实际目标。聊天协议可分别包含 Messages、Chat Completions、Responses 或 Gemini，TypeSafe 使用 System One 非流式选择题。三个对话协议共用主协议的输入和重复回复样本来验证流式、非流式两种模式。具体检测项目和费用以预览为准。每个请求只使用合成数据，不读取客户聊天记录。

## 使用流程

1. 选择账号、模型和检测项目，支持全选/取消全选；批量验收时也可按账号全选。每次最多 25 个账号模型，超过时明确提示分批，不会静默截取或自动发起多批请求。页面不再提供供应商单价和分组选择，按账号自身策略核对 Token。
   检测费用自动使用模型目录价格乘账号成本倍率估算，不代表供应商账单。缺少可用估价会明确提示并阻止预览，不将缺失价格当作零；可取消勾选该模型，或补齐系统价格后重新打开。
2. 预览请求数量和预计费用，确认后执行。预览有效期 10 分钟，实际配置、映射或价格变化需重新预览。
3. 可关闭弹窗，之后通过历史报告重新查看进度。取消后停止派发并尝试取消在途请求，已经接受的上游请求仍可能收费。
4. 报告分开展示原始用量、客户端用量、计费投影。检测不扣客户余额，费用按检测价格和已报告用量计算，不声称与供应商实际扣款一致。

生成请求有输出和时间限制，计数请求有时间限制；跨实例全局最多两个样本同时执行，同账号最多一个。预算在派发前预留；用量不明时保留保守预留。失联/重启时状态不明的请求不自动重放。证据保留 30 天。

## 判断边界

- 没有官方直连基准时，能力测试只能发现异常，不能认证第三方模型或隐藏渠道。第三方返回的模型名称和计数接口均属于上游声明。
- 输入 Token 包含缓存部分，输出 Token 与思考 Token 分栏，避免重复计数。缺失字段显示未知而不是 0。
- 不同请求的输出长度不同、思考量不同，本身不是造假证据。只有可复现的字段丢失、内部矛盾或未遵守校验任务会列入异常证据。
- Token 计量正常不能单独证明扣费正确，单价、倍率和分组优惠需要另行核对。新增页面任务不带分组上下文；历史报告保留原分组、手动价格和配置快照，便于解释旧结果。
- 缓存比率只使用满足条件且有完整统计的请求；新前缀首轮不保证一定冷缓存。隐式缓存没有命中保证，不以一次未命中判定异常。
- 检测不会自动停用账号、调整价格、改变客户计费或更新模型映射。

## 管理 API

沿用现有管理认证与合规确认，以下地址位于 `/api/v1/admin/channel-acceptance`。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/targets?account_ids=1,2` | 已选账号的模型和价格候选 |
| POST | `/previews` | 生成检测清单、成本和配置快照 |
| POST | `/runs` | 使用 `preview_id` 幂等启动 |
| GET | `/runs?account_ids=1,2` | 最近 50 个相关任务 |
| GET | `/runs/:id` | 任务进度和完整报告 |
| POST | `/runs/:id/cancel` | 取消任务 |
| GET | `/runs/:id/export` | 导出脱敏 JSON 报告 |

预览请求示例（账号和模型以实际配置为准）：

```json
{
  "targets": [{
    "account_id": 123,
    "model": "gemini-model-alias"
  }],
  "extras": [],
  "budget_usd": 1
}
```

页面不发送 `price` 和 `group_id`，自动使用可识别的目录价格及账号成本倍率。管理 API 保留这两个可选字段以兼容已有任务与运维调用，价格单位为 USD/百万 Token。`extras` 可包含 `long_context`、`image`、`audio`、`tools`。本功能的预算与客户请求的预扣费上限无关。

## 规则参考与验证

缓存门槛和低思考档位参考 Google 的[缓存文档](https://aistudio.google.com/docs/caching)与[思考参数文档](https://aistudio.google.com/docs/thinking?generate-content=true)，核对日期 2026-11-18。未知模型不猜测缓存门槛，第三方使用相同名称也不证明其后端身份。

流式中断仅保留已观察到的用量；没有上游终态用量时不结清预算预留。验收不写入客户用量、校准或线上账号首字调度统计。

本地定向检查：

```sh
cd backend
go test -p 2 ./internal/service ./internal/handler/admin -run TestAcceptance -count=1
# 仓储集成检查需要项目测试指南规定的独立 PostgreSQL/Redis。
go test -p 2 -tags integration ./internal/repository -run '^TestChannelAcceptance' -count=1
```

第三方计数接口也预留一次生成的预计费用。如果实际返回生成内容，报告标记计数异常，按已观察到的终态用量计算成本，并停止该账号、模型剩余的计数请求；绝不把生成用量或本站回退估算冒充计数接口实测值。第三方忽略协议的实际费用仍不能保证不超过估算。
