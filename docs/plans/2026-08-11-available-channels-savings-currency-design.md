# 可用渠道优惠比例同币种计算设计

## 背景

可用渠道页面同时展示官方 USD 定价与本站 CNY 定价。当前优惠标签直接计算 `1 - 本站 CNY / 官方 USD`，把不同币种的数值放在同一个比例中，导致“省 xx%”被错误展示。

现有 `available_channels_price_cny_multiplier` 是本站人民币展示/充值比例，用于生成本站价，不是美元兑人民币汇率，不能作为官方价换算基准。

## 方案

新增独立设置 `available_channels_official_usd_to_cny_rate`：

- 默认值为 `7`，含义是 `1 USD = 7 CNY`。
- 通过管理员系统设置编辑，并通过公开设置下发给可用渠道页面。
- 本站价计算保持不变：`官方 USD 价 × 分组倍率 × 人民币展示充值比例`。
- 优惠比例改为：`1 - 本站 CNY 价 / (官方 USD 价 × 官方 USD/CNY 汇率)`。
- 汇率为 `0`、非有限值、官方价不大于 `0`、本站价无效或本站价不低于官方人民币基准时，不展示优惠标签。

## 数据流

管理员设置 → 后端设置存储/解析 → 公开设置响应 → `AvailableChannelsView` → 目录价格上下文 → 每个价格值保存官方人民币基准 → 共享价格比较函数生成优惠比例。

该设置只影响页面展示，不参与真实扣费、分组倍率或用户余额计算。

## 测试

- 后端：默认汇率为 `7`，自定义值能被公开设置完整下发，负数被拒绝。
- 前端目录模型：官方人民币基准由官方 USD 价与汇率生成，非法/零汇率不生成基准。
- 前端价格卡片：`$5`、本站 `¥0.60`、汇率 `7` 显示“省 98%”；汇率为 `0` 时不显示优惠标签。
- 页面集成：公开设置中的汇率被传入目录构建链路。
