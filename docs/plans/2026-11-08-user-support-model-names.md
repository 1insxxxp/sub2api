# 用户支持完整调用模型名

用户已确认修复并部署。使用记录与错误记录保留完整公开 requested_model，并标注“调用模型”，分组独立显示。

## 实现
- 保留已审核模型的安全公开前缀；新增模型与自定义别名通过该记录来源分组的本地公开模型声明核对。复用分类目录声明逻辑，不请求上游，不以调度临时状态判断历史名称。
- 仓储只读取 requested_model，内部查询上下文不序列化；服务层再次校验。缺失、未知或敏感值继续隐藏，不回退映射后模型。当前声明已删除且不属于已审核模型的历史别名保留未知。
- 每次查询合并两个面板的来源分组，一次有界目录读取；目录失败时保留已审核名称与其它查询结果。
- 两类卡片使用同一标题结构，完整名称可换行，浅深色与移动布局沿用现有样式。
