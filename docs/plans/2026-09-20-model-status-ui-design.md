# 模型状态页面 UI 优化设计

## 目标

保留模型状态页现有的成功率、健康状态、15 分钟结果桶、点击详情、分组筛选和自动刷新能力，将页面接入已确认的用户工作区视觉基准，并修复移动端深色 sticky 工具栏、模型身份区和分组上下文的可读性问题。

## 设计

- 页面外壳、标题栏、筛选区和模型卡使用 `workspace-tokens.css` 的中性半透明 surface、细边框、内侧高光和柔和阴影；品牌蓝只用于主要操作和选中态，状态色只用于成功/失败/空/降级提示。
- 移动端模型卡使用单列布局。模型名允许任意位置换行，成功率/结果计数/健康状态按优先级稳定换行，健康 badge 不强制挤在同一行。
- 深色模式的 sticky 工具栏和筛选区使用同一套深色 surface，不出现浅色背景带。分组上下文保留可见名称，IntersectionObserver 只负责更新，不隐藏唯一上下文来源。
- 刷新失败提示提供重试入口；筛选无结果时提供清除筛选操作。所有新增操作满足键盘焦点、44px 触控尺寸和 reduced-motion。
- 保持 API、自动刷新、滚动加载、capture 模式和桶详情数据逻辑不变。

## 验证

更新 `ModelStatusView.spec.ts`，覆盖材质语义类、失败重试、空筛选清除、移动端结构契约和深色 sticky 类。运行模型状态定向测试、类型检查、Lint 和构建。
