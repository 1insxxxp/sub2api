# 兑换码多选批量复制设计

## 目标

在用户兑换码列表中增加“批量复制”操作，让用户可以将当前勾选的多个兑换码一次性复制到剪贴板，每个兑换码占一行，并保持移动端工具栏整齐可用。

## 方案

复用 `RedeemView.vue` 已有的 `selectedGeneratedCodeIds` 选择状态和兑换码列表数据，不新增独立的选择模型。批量复制操作按列表展示顺序筛选当前勾选项，将其 `code` 字段用换行符连接后调用现有剪贴板写入逻辑。

按钮放在生成兑换码区域的选择工具栏中，与“全选”和“批量删除”并列；没有勾选项时禁用，避免复制空内容。复制成功沿用现有成功提示，剪贴板异常沿用现有失败提示。新增中英文 locale 文案，不改变已有“复制全部生成结果”行为。

## 数据流与边界

1. 用户勾选兑换码后，按钮依据 `selectedGeneratedCodeIds.length` 更新可用状态。
2. 点击批量复制时，从当前兑换码列表中过滤出仍存在且已选中的项目，保持列表顺序。
3. 过滤结果为空时直接返回；否则复制 `code1\\ncode2` 格式的文本。
4. `navigator.clipboard.writeText` 成功或失败分别复用现有通知方式。

## 测试

- 无选择时批量复制按钮处于禁用状态。
- 选择多个兑换码后，点击批量复制会按列表顺序写入仅包含选中兑换码的换行文本。
- 剪贴板写入失败时显示既有复制失败提示。
