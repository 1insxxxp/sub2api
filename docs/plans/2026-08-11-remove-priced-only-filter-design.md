# 移除“仅显示有价模型”筛选设计

## 背景

可用渠道页面会为缺少渠道定价的已知模型补充全局展示价格。当前线上 Anthropic 渠道的 13 个模型因此全部被判定为“有价模型”，用户切换“仅显示有价模型”时页面没有任何变化，容易被理解为按钮失效。

## 方案

从可用渠道工具栏移除“仅显示有价模型”开关，同时删除页面中的 `pricedOnly` 状态、双向绑定以及工具栏对应的属性和事件。工具栏保留搜索、平台筛选和刷新按钮，并重新调整响应式网格列数，避免留下空白位置。

底层目录筛选函数暂时保留 `pricedOnly` 能力，由页面固定传入 `false`。这样既删除了无价值的用户入口，又不扩大到公共目录模型与现有单元测试的重构。

## 数据与接口

不修改后端接口、数据库、定价回落或真实计费逻辑。可用渠道数据加载、搜索、平台筛选和刷新行为保持不变。

## 验证

- 工具栏不再渲染 `priced-only-filter`。
- 工具栏不再声明或触发 `update:pricedOnly`。
- 搜索、平台筛选和刷新事件继续工作。
- 响应式筛选栏变为移动端两列、桌面端三列。
- 运行工具栏、目录筛选以及前端类型检查。
