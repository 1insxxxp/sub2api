# 收益日历响应式重排设计

## 目标

重排管理员页面的消耗日历和日期明细，使桌面端信息层级清晰，并确保 360px 以上移动端能够完整查看日期、余额消耗、收益金额、分组名称和展开操作，不发生金额或按钮断行挤压。

## 布局方案

- 日历日期格只承担日期、是否有数据和当前选中状态，不再在格内展示完整金额。
- 月度汇总改成两个并列摘要块，分别展示余额消耗和收益金额。
- 选中日期后，在日历下方展示该日完整金额摘要；移动端可直接读取，桌面端也不需要从日期格中辨认数字。
- 桌面端使用约 60%/40% 的日历和日期明细分栏，明细区域采用稳定的分组卡片布局。
- 小于 `xl` 的宽度改为单列，日期明细位于日历下方；移动端分组名称、用量、两种金额和展开按钮分区排列。

## 交互与数据

- 保留现有月份选择、日期选择、分组展开、请求流水分页和 API，不修改后端协议。
- 日历中的可授权日期仍然可点击；无权限日期保持禁用。
- 移动端仍默认选中最近一个可见日期，但只显示一份选中日摘要，避免重复列表不断向下延伸。

## 验证

- 更新工作台组件测试，验证日期格不再承载金额、选中日摘要包含完整金额、日期明细卡具备移动端稳定布局。
- 执行工作台测试、前端类型检查，并在桌面与移动视口进行截图检查。
