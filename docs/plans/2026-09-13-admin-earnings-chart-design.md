# 管理员收益管理与每日收益图表设计

## 背景

管理员工作台当前默认打开“额度转兑换码”，而“收益管理”位于第二个标签。收益接口已经按月份返回授权期间的每日余额消耗和收益金额，但页面只用日历展示这些数据，趋势变化不够直观。

## 目标

1. 将“收益管理”放在工作台第一个标签，并作为默认打开的面板。
2. 在收益管理的月份汇总和日历之间增加每日收益趋势图。
3. 保持现有接口、主题色、日历点击明细和移动端体验不变。

## 方案

复用现有 `GET /admin/workbench/commission/calendar` 数据，不增加后端端点或重复请求。日历组件继续负责月份选择和数据加载，并把同一份按日期排序的数据传给新的 `SubAdminCommissionTrendChart` 组件。图表使用项目已有的 Chart.js/vue-chartjs 依赖，绘制两条金额折线：

- 收益金额（主指标，绿色）
- 余额消耗（辅助指标，蓝色）

图表横轴使用当前月份的 `MM-DD`，保留后端返回的零值日期以避免时间轴断裂；月份切换时由现有数据响应式更新。加载中显示脉冲占位，无数据显示现有本地化空状态；图表容器使用 `min-w-0` 和固定响应式高度，图例及刻度在窄屏自动收缩。颜色跟随页面浅色/深色主题。

标签顺序、键盘导航顺序和默认 `activeTab` 同步改为 `commission → balance-transfer → affiliate-leaderboard`。

## 验证

- 为趋势图组件增加单元测试，验证日期排序、两组数据对齐、零值保留、加载和空状态。
- 更新工作台测试，验证收益标签首位、默认选中及键盘导航顺序。
- 更新移动端源码断言，验证图表宽度安全样式。
- 运行相关 Vitest、前端类型检查、i18n 检查和生产构建。
