# Model Status Refresh Countdown Design

**Goal:** 在模型状态标题栏展示下一次自动刷新的倒计时，让用户知道数据何时更新。

**Design:** 复用模型状态页现有的 30 秒自动请求周期，新增一个每秒递减的倒计时状态。页面首次加载和每次刷新请求完成后将倒计时重置为 30 秒；手动刷新沿用现有请求流程，完成后同样重置。请求进行中保留刷新图标的加载状态，不额外引入新的请求或后端接口。

**Presentation:** 倒计时放在标题栏刷新按钮左侧，桌面端显示“自动刷新 · N 秒”，小屏显示紧凑的“N 秒”，并保持刷新按钮可用的固定尺寸。倒计时提供可读文本和 `aria-live="polite"`，不依赖颜色传达状态。

**Testing:** 使用现有 Vitest fake timers 验证初始值、每秒递减、自动轮询和手动刷新后的重置；继续运行模型状态页的定向测试及前端类型检查和构建。
