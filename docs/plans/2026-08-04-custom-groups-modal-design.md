# 自定义分组弹窗化设计

## 目标

用户在 API 密钥页内完成自定义分组管理，不发生路由跳转；桌面端使用宽弹窗，移动端使用全屏式单层工作区。

## 交互结构

- API 密钥工具栏使用醒目的琥珀色“自定义分组”按钮。
- 点击后打开 `BaseDialog`，不修改当前路由。
- 弹窗内部有两种互斥状态：分组列表、分组表单。
- 从列表点击新建或编辑进入表单；表单顶部和底部均提供明确返回/取消路径。
- 保存后返回列表并刷新数据；关闭弹窗后仍停留在 API 密钥页。
- `/custom-groups` 兼容路由复用同一个管理工作区。

## 响应式

- 桌面端最大宽度使用 `full` 弹窗规格，内容高度限制在视口内。
- 移动端弹窗占满可用视口，列表或模型选择区独立滚动。
- 操作按钮在窄屏下保持足够点击面积，并可换行或铺满宽度。
- 不使用嵌套弹窗，避免焦点、返回和软键盘冲突。

## 验证

- API 密钥入口不再包含 `/custom-groups` 路由跳转。
- 点击入口打开管理弹窗。
- 工作区源码不包含嵌套 `BaseDialog`。
- 路由兼容页继续包含 `AppLayout` 并复用工作区。
- 执行相关测试、全量前端测试、类型检查和生产构建。
