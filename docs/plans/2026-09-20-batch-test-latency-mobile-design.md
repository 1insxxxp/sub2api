# 批量模型测试耗时与移动端适配设计

## 目标

在批量账号模型测试结果中显示每个模型的请求耗时，并让本次新增和调整的测试界面在窄屏设备上保持可读、可操作和不横向溢出。

## 设计

继续使用现有批量测试流程。`durationMs` 已由前端在每个模型请求开始和 SSE 结束之间测量，作为端到端请求耗时展示；它包含网络、服务端处理、SSE 读取和前端解析，不声称是纯上游服务端耗时。成功和失败结果都显示耗时，等待中、测试中和未开始的项目不显示虚假耗时。小于 1000ms 显示毫秒，否则显示两位小数秒。

移动端适配只调整管理员账号测试弹窗的布局：底部操作按钮在窄屏纵向全宽排列，桌面端保持横向；批量汇总在窄屏使用两列网格；模型结果行在窄屏纵向排列，模型名可收缩截断，状态、耗时和错误信息允许换行；账号名称、测试模式摘要、终端长文本和复制按钮补充收缩、换行或触屏可见规则。BaseDialog 的已有底部弹窗和安全区行为继续复用。

## 测试

增加组件测试验证成功和失败模型都带有确定耗时，并用静态类名断言覆盖移动端纵向按钮、结果行换行和复制按钮触屏可见。继续运行现有批量、单模型、国际化和类型检查。
