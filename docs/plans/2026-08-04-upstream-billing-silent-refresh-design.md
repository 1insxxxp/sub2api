# 上游声明倍率静默刷新设计

## 问题

账号管理中，单个或批量刷新上游声明倍率后会调用账号列表 `load()`。通用表格加载器会将 `loading` 置为 true，导致整张表格闪烁或进入骨架加载状态。虽然探测接口已经返回最新倍率快照并完成局部更新，仍需要后台同步当前页，以获取后端可能同时更新的账号倍率、排序及其他字段。

## 方案

- 为 `useTableLoader.load` 增加可选 `{ silent: true }` 参数。
- 静默加载执行与普通加载相同的请求、分页数据替换和取消逻辑，但不主动打开整表 loading。
- 无论普通或静默请求，当前有效请求结束时都负责关闭 loading，避免静默请求取消普通请求后 loading 卡住。
- AccountsView 的倍率探测完成后继续先局部 patch 返回快照，再调用当前页静默加载。
- 单个和批量探测共用同一个静默同步函数。

## 验证

- composable 测试验证静默加载期间 `loading` 始终为 false，数据仍更新。
- composable 测试验证静默请求接替普通请求后不会遗留 loading。
- AccountsView 测试或源码契约验证倍率刷新使用静默加载。
- 运行相关测试、类型检查与生产构建。
