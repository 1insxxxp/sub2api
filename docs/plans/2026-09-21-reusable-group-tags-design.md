# 可复用自定义分组标签设计

## 目标

让已经使用过的自定义分组标签在新建和编辑分组时以可选项出现，并复用其最近的颜色配置；预设的 `chat`、`image`、`airp` 保持现有行为。

## 方案

继续使用现有 `groups.tag` 和 `groups.tag_color` 字段，不新增表或迁移。管理员分组页调用已有的全量分组接口，收集所有分组的非预设、非空标签，按标签文本去重，记录使用次数和一个有效颜色。自定义标签选项由 `GroupsView` 传给 `GroupTagField`，因此只影响分组管理表单。

`GroupTagField` 将预设选项与“已保存标签”分区展示。选择已保存标签时同时发出 `update:modelValue` 和 `update:color`；手动输入和颜色编辑仍只修改当前表单。当前分组独立使用，改名或改色不会同步其他分组。

## 数据流与容错

1. 页面加载时请求包含停用分组的全量列表，构建去重标签选项。
2. 创建、编辑、删除或刷新分组后重新加载标签选项，确保新标签立即可复用。
3. 预设标签不进入自定义列表，空白标签和非法颜色被忽略。
4. 全量标签请求失败时静默保留手动输入能力，不阻断分组表单。
5. 现有后端字段、权限、请求负载和分组展示保持不变。

## 验证

- `GroupTagField` 测试覆盖自定义选项展示及选择时同步颜色。
- `GroupsView` 测试覆盖标签去重、预设过滤和加载失败回退。
- 运行相关前端测试、类型检查和构建。
