# 可用渠道彩色模型卡片网格设计

## 目标

将现有偏管理后台表格风格的“可用渠道”页面重构为更接近 new-api 模型广场的信息卡片界面。模型品牌识别和价格对比必须在首屏一目了然，同时保留现有渠道、分组、筛选、倍率与计费逻辑。

## 视觉方向

采用紧凑的彩色模型卡片网格。每张卡片以模型为主体，通过厂商彩色图标和品牌色建立快速识别；本站价是首要视觉信息，官方价和节省比例构成直接对比。整体保持当前 Passion API 后台的浅色、克制风格，不照搬 new-api 源码或完整主题。

## 页面结构

- 顶部继续保留搜索、平台筛选、仅看有价和刷新操作。
- 桌面端使用响应式卡片网格，大屏每行 3–4 张，中屏每行 2 张。
- 移动端使用单列卡片，所有关键价格无需横向滚动即可查看。
- 渠道选择仍保留桌面侧栏与移动端底部选择器，但不抢占模型与价格的视觉层级。

## 模型卡片

### 头部

- 显示厂商彩色图标、模型名和平台标签。
- OpenAI、Anthropic、Gemini 等常见平台使用各自可辨识的颜色体系；未知平台使用稳定的通用图标和中性色。
- 长模型名允许换行，不挤压价格区域。

### 价格区

- 本站价使用更大字号和高对比品牌色。
- 官方价使用较小字号；存在真实优惠时使用删除线。
- 同时存在可比较的官方价与本站价时，显示“节省 xx%”标签。
- 输入、输出、缓存、按次和图片等关键价格直接展示在卡片中。
- 阶梯价格显示起始价和“阶梯价”提示，展开后查看完整区间。
- 合法零价格显示为 0，不误判为未定价。
- 没有任何有效价格时显示“暂未定价”，并降低卡片价格区的视觉权重。

### 次级信息与展开区

- 卡片底部显示可用渠道数、分组数和方案数。
- “查看方案”展开后列出每个渠道、分组、平台及完整官方价/本站价明细。
- 同名模型在不同渠道或分组中的方案保持独立，不合并为错误价格。
- 展开状态继续使用稳定模型键保存，刷新和重排不应意外丢失。

## 价格口径

- 继续复用现有 catalog 和共享价格格式化逻辑，不在 UI 中重新计算计费价格。
- Token 价格统一显示每 1M token；按次和图片价格分别显示每次、每张。
- 节省比例仅在官方价大于零、本站价有效且二者计费维度一致时计算。
- 代表价必须标明口径，不能让用户误解为所有渠道统一价格。

## 响应式与无障碍

- 卡片在 320px 宽度下不得产生页面级横向滚动。
- 操作按钮至少 44px 可点击高度。
- 展开按钮保留 `aria-expanded` 和唯一 `aria-controls`。
- 图标颜色不是唯一信息来源，同时提供平台文字。
- 支持键盘操作、焦点可见、深色模式和减少动画偏好。

## 状态

- 首次加载显示卡片骨架屏。
- 刷新时保留已有卡片，仅显示轻量刷新状态。
- 区分无渠道数据、筛选无结果、选中渠道无模型、倍率加载失败和未定价模型。

## 验收标准

- 用户无需展开即可识别模型厂商并看到本站价、官方价和优惠幅度。
- 输入、输出、缓存、按次或图片等适用价格能在卡片首层读取。
- 桌面和移动端均无横向溢出，模型多时仍具备良好浏览密度。
- 渠道/分组方案展开后信息完整，现有计价结果不发生变化。
- 中英文文案、组件测试、类型检查、Lint 和生产构建全部通过。
