# API 密钥分组选择器移动端底部弹窗设计

## 问题

API 密钥列表中的分组选择器使用 Teleport 浮层。现有实现仅按浏览器视口夹取宽度，并在 `640px` 以上固定为 380px；当页面已经使用移动卡片布局、但视口宽度处于 640–767px 时，选择器仍采用桌面浮层，遮挡卡片且视觉上超出内容区。

## 方案

- 视口宽度小于 768px 时，使用带遮罩的底部弹窗：左右和底部留 8px，宽度由 inset 决定，列表内部滚动。
- 视口宽度达到 768px 时，继续使用锚定触发按钮的桌面下拉框。
- 搜索、分组描述、倍率、选择与关闭逻辑保持不变。
- resize 时仍关闭选择器，避免模式切换后保留旧定位。

## 验证

- 源码布局测试先证明当前缺少移动端底部弹窗结构。
- 修复后验证移动分支具有遮罩、底部定位和 768px 断点，桌面分支仍使用计算定位。
- 运行 KeysView 相关测试、类型检查与生产构建。
