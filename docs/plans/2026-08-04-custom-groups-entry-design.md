# 自定义分组入口调整设计

## 目标

自定义分组是 API 密钥的辅助配置，不再占用独立的左侧导航项。用户从 API 密钥页进入管理页面。

## 交互

- 删除普通模式和简单模式侧边栏中的“自定义分组”。
- 在 API 密钥页工具栏中增加“自定义分组”次要按钮，与“创建密钥”并列。
- 点击按钮进入现有 `/custom-groups` 路由。
- 自定义分组页面继续使用 `AppLayout`，保留统一顶栏、侧栏和返回路径。

## 范围

不修改后端 API、数据库结构、自定义分组路由或 API Key 绑定逻辑。

## 验证

- 契约测试确认侧边栏不含该入口。
- 契约测试确认 API 密钥页包含入口按钮并指向 `/custom-groups`。
- 执行前端类型检查和相关测试。
